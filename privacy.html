トップ利用規約English

KANOHSHIKI（運営: NAO UESAKI。以下「当方」）は、当方の分析・制作ツール「K.Y.O.U.」（以下「本ツール」）で扱う情報を、次のとおり取り扱います。 本ツールは一般の方に公開するサービスではなく、当方自身のアカウントと、当方と合意したクリエイター（以下「パートナー」）のアカウントにだけ使います。

1. 取得する情報

アカウントの持ち主が公式の画面で「許可」したときだけ、次の公式 API を通じて取得します。パスワードは受け取りません。

サービス取得する情報
YouTube（YouTube Data API・YouTube Analytics API・YouTube Reporting API） チャンネルの ID・名前・登録者数・総再生数、動画の ID・タイトル・URL・公開日時・長さ、 動画ごとの再生数・高評価・コメント数・共有数・視聴時間・平均視聴率・インプレッション・クリック率、視聴者の属性の集計（年齢層・地域など。個人は特定しません）
Instagram（Instagram API with Instagram Login） アカウントの ID・ユーザー名・フォロワー数・投稿数、投稿の ID・キャプション・URL・投稿日時、 投稿ごとの再生・リーチ・いいね・コメント・保存・シェア・視聴時間、フォロワーの属性の集計

コメントの本文・DM・他の利用者の個人情報は取得しません。

2. 使う目的

  • アカウントの持ち主の投稿の成績を分析し、次の作品・投稿の改善に役立てるため
  • アカウントの持ち主（パートナー）への成績の報告のため
  • 当方自身のアカウントについて、当方が承認した動画を投稿するため（YouTube への動画のアップロード。パートナーのアカウントには投稿しません）

広告・販売・第三者のための分析には使いません。

3. 保管と安全管理

  • 取得した情報は、当方が管理する日本国内のコンピューターにだけ保管し、クラウドのデータベースには置きません。
  • 許可の証明（アクセストークン）は、OS の資格情報マネージャーに暗号化して保管し、画面・記録には表示しません。
  • パートナーごとに保管場所を分け、他のパートナーや当方の情報と混ぜません。

4. 第三者への提供

法令に基づく場合を除き、取得した情報を第三者に提供・販売しません。

5. Google のユーザーデータの扱い

本ツールが Google API から受け取った情報の使用と移転は、 Google API サービスのユーザーデータに関するポリシー （限定使用の要件を含む）に従います。本ツールは YouTube API サービスを使用しています。 YouTube 利用規約・Google プライバシーポリシーもご確認ください。

6. 許可の取り消しと情報の削除

  • Google（YouTube）: Google アカウントのサードパーティ アクセスから「K.Y.O.U.」のアクセスを削除できます。
  • Instagram: Instagram の「設定」→「ウェブサイトのアクセス許可」→「アプリとウェブサイト」から「KYOU」を削除できます。
  • 取り消し後は新しい情報を取得しません。保管済みの情報の削除は、下の連絡先にご連絡ください。30 日以内に削除し、完了をお知らせします。 パートナーとの契約が終わったときは、そのパートナーの情報をまとめて削除します。

7. 保管期間

分析に必要な間（パートナーの場合は契約の間）保管し、不要になったら削除します。

8. 改定

内容を変えるときは、このページで施行日とともにお知らせします。

Privacy Policy (English summary)

KANOHSHIKI (operated by NAO UESAKI) uses its internal tool "K.Y.O.U." only for its own accounts and for creators who have agreed to work with us. With the account owner's explicit permission through the official consent screens, we read channel/account and post statistics via the YouTube Data, Analytics and Reporting APIs and the Instagram API with Instagram Login (listed in section 1). We never receive passwords, and we do not collect comment text, messages, or other users' personal data.

We use the data only to analyse and improve the owner's content, to report to partners, and to upload videos we have approved to our own YouTube channel. Data is stored only on computers we manage in Japan; access tokens are kept encrypted in the operating system's credential store. We do not sell or share data with third parties except as required by law.

K.Y.O.U.'s use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. This tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access and deleting data: remove "K.Y.O.U." at Google Account third-party access, or remove "KYOU" in Instagram Settings → Website permissions → Apps and websites. To delete stored data, contact us below; we delete it within 30 days and confirm.

Contact: audiscript.project@gmail.com
